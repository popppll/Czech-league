## AI Weather 3.0 (v48)

`AI-Weather-1-rijna-v48.html` je celá appka (PWA v jednom souboru) s novou verzí **AI Weather 3.0** pro všechny tři modely (⚡ Flash · 🧠 Ultrathinking · 🛰 Ultraagent).

Zdrojáky nové vrstvy jsou ve složce `ai3/` (čitelné části `*.js`, `ai3.css`). Po úpravě je složí zpátky do HTML:

```
python3 ai3/build.py          # vyžaduje Node.js (kontrola syntaxe)
```
